# 手机维修扫码派单管理系统 V1.0

项目业务规则见 [项目边界.md](项目边界.md)。当前代码包含 Node.js + SQLite 后端、管理员电脑网页后台、原生微信小程序。金额在数据库中按“分”存储。

## 本地启动

需要 Node.js 22.13 或更高版本。PowerShell：

```powershell
$env:ADMIN_PASSWORD = '请设置至少5位的管理员密码'
$env:SUPERADMIN_PASSWORD = '请另设至少5位的超级管理员密码'
npm start
```

普通管理员入口为 `http://localhost:3000/shouji`，师傅网页端为 `/shifu`，超级管理员入口为 `/chaojishouji`。首次账号默认为 `admin` 和 `superadmin`，密码分别为上面设置的值。超级管理员可创建普通管理员；普通管理员只能创建前台和师傅账号。首次启动后账号保存在 `data/repair.sqlite`，后续修改环境变量不会改动已有密码。可用 `ADMIN_USERNAME`、`SUPERADMIN_USERNAME` 指定首次账号，`PORT` 修改端口，`DATA_DIR` 指定数据库目录。

线上 `www.xiangyuzhubao.xyz` 的初始登录账号：超级管理员为 `admin`，原普通管理员为 `repair_admin`。两级管理员登录后可在“我的资料”中设置中文显示名称，也可修改自己的登录账号；改登录账号时需要输入当前密码。人员管理创建普通管理员时可直接填写显示名称。环境变量仅用于首次创建账号，不会覆盖已修改的资料。账号密码不写入项目文件。

`npm test` 运行完整业务流程测试。数据库每日自动备份到 `data/backups/`；系统运行期间会每小时检查一次当天是否已有备份。部署时还应备份整个 `data` 目录到另一台设备或云存储。

## 微信小程序

用微信开发者工具导入 `miniprogram` 目录。`miniprogram/app.js` 已指向 `https://www.xiangyuzhubao.xyz`；请在微信公众平台把该域名加入 request 合法域名，并把 `miniprogram/project.config.json` 中的体验 AppID 换成自己的小程序 AppID。开发工具本地调试可改用本机地址；真机和发布必须使用合法域名。前台账号由管理员在网页创建；师傅可在小程序注册，管理员审核后登录。

## 已实现的流程

- 前台录入完整串码、型号、客户、方案、收费和工价，选择师傅时显示 VIP 等级。
- 师傅只能查询自己的订单项目；转派后旧师傅无法继续操作。
- 项目完成时写入时间、收费和工价快照，以及不可重复的财务流水；重试完成返回已完成。
- 退机、取消订单对已完成项目生成负数冲销流水；未完成项目不计价。
- 追加项目独立结算，财务可按日期、师傅、串码查询并导出 Excel 可打开的 CSV。
- 金额和订单操作保存审计记录。

## 需要上线前配置

正式运营需要 HTTPS 域名、小程序 AppID、服务器运行与异地备份。系统当前使用账号密码登录小程序；如需微信授权登录或消息通知，需要另行配置微信开放能力。客户收费目前作为项目完成时的收入入账，退机或取消时冲销；如实际业务按收款时间记账，应在上线前调整账务规则。


## 登录入口与会话互斥

- 前台和普通管理员：`/shouji`；超级管理员：`/chaojishouji`；师傅网页端：`/shifu`。
- 三个网页入口使用统一中文登录设计；小程序登录和注册页同步更新。
- 同一个账号仅保留最近一次登录。包括师傅网页端与小程序，后登录会让前一次令牌失效。
- 同一个浏览器登录其他入口，会清除其他入口的本地登录态并注销旧令牌，已打开的页面自动回到登录界面。
- 令牌绑定来源，请求携带对应来源。来源不符或令牌失效时返回重新登录提示；权限仍由服务端账号角色决定。
- 不同账号在不同浏览器或设备上可同时工作。小程序保留原有角色功能。
- 发布时需同时更新服务器和 public 静态资源，并重新发布小程序；仅更新本地源码不会改变线上页面。
